    04
    
      
    Payloads I built from the ground up
    
      
    Side projects where I wrote the model, the training loop, and sometimes the whole simulator.
    
      
    
        
    
          
    HelpSteer Transformer
    
          
    PyTorch, Transformers
    
          
    A 60M-parameter transformer with rotary position embeddings, SwiGLU and RMSNorm, built for attribute-conditioned generation. Learned embeddings injected at the input give explicit control over five response attributes: helpfulness, correctness, coherence, complexity and verbosity.
    
          
      
            
    • 60M parameters
      • 
            
    • 48% leaner than baselines
      • 
            
    • 4,200 tokens/s inference
      • 
          
    
        
    
        
    
          
    Multi-track racing with Deep Q-Learning
    
          
    PyTorch, PyGame
    
          
    A Dueling Double DQN that learns to drive seven tracks from a 24-dimensional state (15 ray-cast sensors plus vehicle dynamics). I wrote the 60 FPS physics simulation myself. A curriculum moves the agent from ovals to figure-8s, with prioritised replay and τ = 0.001 soft target updates.
    
          
      
            
    • 85%+ track completion
      • 
            
    • 7 track layouts
      • 
            
    • 0 expert demonstrations
      • 
          
    
          Source on GitHub
        
    
        
    
          
    Stable Diffusion from scratch
    
          
    PyTorch, Diffusion, Gradio
    
          
    The CLIP text encoder, U-Net denoiser and VAE decoder written by hand, with custom conditioning for style and composition. Mixed precision and attention slicing cut VRAM use by about 50% with no visible quality loss.
    
        
    
        
    
          
    Log anomaly detection
    
          
    scikit-learn, Isolation Forest, MLflow
    
          
    Unsupervised detection over server logs using statistical, n-gram and temporal features, with configurable real-time alerting. Mean time to detection fell by around 60% in production.
    
        
    
        
    
          
    Skin cancer classifier
    
          
    PyTorch, Medical imaging
    
          
    Multi-class dermatology classification on a small dataset: heavy augmentation, ResNet and EfficientNet transfer learning, weighted loss for imbalance and attention maps so predictions can be checked.
    
        
    
        
    
          
    Face Mesh Retouch
    
          
    Android, OpenGL ES 3.0, NDK
    
          
    Real-time face retouching on the phone GPU with MediaPipe face-mesh landmarks and custom GLSL shaders for smoothing, colour and geometry. The C++ path runs about 3x faster than Java at 60 FPS.
    
        
    
        
    
          
    Sentiment analysis service
    
          
    NLTK, VADER, RoBERTa, Django
    
          
    Scores brand comments with VADER and RoBERTa, emails an alert when sentiment shifts (watchdog plus SMTP), and exposes it all through a Django REST API tunnelled with Cloudflare.
    
          Source on GitHub
        
    
      
    
    
    
  
    

  
  
    
    
    
      
    05
    
      
    Satellites in orbit
    
      
    Three Python packages on PyPI, each with tests, CI and honest notes on what it can't do.
    
      
      
        
    • 
          
      styletransfer-lite
      v0.1.0
      
          
      Fast neural style transfer: 26 built-in styles, or any painting as the style. Runs on onnxruntime, so the install is megabytes instead of a full framework, and a 1024-pixel photo takes about half a second on a laptop CPU. CLI, GUI and video.
      
          
      pip install styletransfer-lite
      
          Repository
        
      • 
        
    • 
          
      facetweak
      v0.2.0
      
          
      Face retouching from the command line or Python. 23 landmark-guided adjustments to eyes, brows, nose, lips and jaw using smooth local warps, not a generative model, so texture and lighting stay real. CPU only, well under a second.
      
          
      pip install facetweak
      
          Repository
        
      • 
        
    • 
          
      stylematch
      v0.1.3
      
          
      An AI-text detector (neural, GPU optional) plus a writing-style comparison tool for the "do these sound like the same person?" question. CLI, Python API and a small desktop app.
      
          
      pip install "stylematch[ai]"
      
          Repository

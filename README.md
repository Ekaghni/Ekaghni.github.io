# Mission EKAGHNI-01

Personal portfolio of Ekaghni Mukherjee, R&D Machine Learning Engineer.

A scroll-driven flight through a procedurally generated solar system (Three.js shaders), covering experience, projects, open-source packages, skills, and an interactive star map of an 87-lesson AI/ML curriculum.

Static site, no build step. Serve the folder with any static server, e.g. `python -m http.server`.
